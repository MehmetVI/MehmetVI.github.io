# Rush Out public website

Static, dependency-free GitHub Pages website. Publish these files at the root of `MehmetVI.github.io`. No game source belongs in that public repository.

## Before publishing

- Public contact: `support.rushout@gmail.com`, previously recorded in the project’s store and privacy documentation.
- Verify the policy against the released build and update its date/content whenever data use changes.
- `app-ads.txt` is deliberately absent: add only the exact authorized seller record supplied by AdMob after the publisher ID is known.
- Set the App Store developer/marketing URL to the site origin when appropriate; AdMob discovers the root host from the store listing.

Routes: `/`, `/tr/`, `/privacy/`, `/privacy/tr/`, `/support/`, `/support/tr/`. All assets are local; no JavaScript, external fonts, analytics or cookies are used by the site. Hosting provider request logging is disclosed in the policy.
